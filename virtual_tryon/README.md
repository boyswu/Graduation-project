## 当前效果

- 双肩可见即可自动换衣；肘部、髋部可在画面外，半身模式按肩宽估算画面外躯干。
- CatVTON 输出完整人物换衣照片；主画面随后进行衣层裁切和二维 Warp，属于实验对照，存在贴图和遮挡限制。

- 三套服装可切换；每套服装生成一次 AI 衣层，之后由本地 36×54 网格 Warp 实时变形。
- MediaPipe 姿态、实时分割和生成图分割在独立 Worker 运行；只保留一个待处理相机帧，绘制线程继续播放。
- 使用 requestVideoFrameCallback 识别真正的新相机帧，避免用连续递增的 currentTime 重复上传同一帧；面板显示真实相机帧率。
- 无摄像头时可进入合成演示；CatVTON 离线时仍保留姿态预览和明确错误提示。

## 已知限制

- AI 推理是**关键帧生成**，不是逐帧生成式视频试衣；当前 HTTP 中位数本机 4.76 秒、远端 0.96 秒，首次浏览器分割另需初始化。
- AI 衣层捕获后使用 2D 锚点网格跟随，侧身、手臂遮挡、袖口和衣摆真实感仍有限。
- 当前求解器不能处理任意服装拓扑、360° 人体重建和真实布料物理。
- 生成质量依赖正面姿态、服装参考图、人体掩膜与随机种子；换人后需要重新生成。
- CatVTON 代码和权重为 `CC BY-NC-SA 4.0`，仅用于非商业本科研究和现场演示。
- 5090 推理已通过 8021 隧道部署；8010 仍仅为可选 WebSocket RTT 诊断。

## 重连与重复测速

`scripts/start-remote-tunnel.ps1` 隐藏启动 SSH 守护进程，断线后重新查询工作空间端口；
本次强制断线后 34.8 秒恢复。要求 CLI 当前环境为 OpenBayes / OB-Intern，工作空间已运行。
脚本不会启动或重启 GPU 容器。直接运行默认绑定 localhost:8021；`start-demo.ps1 -Remote` 使用8022转发到远端8030，并启用`-EnsureFullFrameService`：首次连接或SSH重连时，检查原FluxRT进程，缺失则启动已安装的服务，随后等待模型就绪。它校验PID对应的命令并避免重复启动；8030被未知进程占用时直接报错，不终止该进程。
旧5090 CatVTON隧道可单独运行 `scripts/start-remote-tunnel.ps1`；本机4060旧模型需显式启动，远程模式不依赖它。

复测使用 `scripts/benchmark.py`，将图片参数换成同一套人物、服装和掩膜路径：

```powershell
python -B scripts/benchmark.py --person C:\samples\person.jpg --garment C:\samples\garment.jpg --mask C:\samples\mask.png --url http://127.0.0.1:8020 --url http://127.0.0.1:8021 --runs 5 --format compact
```

输出默认写入系统临时目录；可用 `--format png` 或 `--format lossless` 比较传输格式。
