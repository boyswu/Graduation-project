# 毕设材料与证据索引

题目：基于深度学习的交互式虚拟试衣系统设计与实现

本目录提供通用本科版完整章节初稿及配套工作材料；个人信息、学校模板和GPU恢复后的真人复测由本人补齐。未虚构新的GPU测试、训练模型、用户研究或质量分数。

## 文件

- 毕业论文初稿.docx 与同名.md：中英文摘要、七章正文、参考文献与附录，可编辑。
- 毕设配套材料.docx 与同名.md：项目简介、任务书草案、开题报告、设计说明、操作与部署手册、实验表、五分钟答辩讲稿、问答和提交检查表。
- 答辩演示.html：浏览器演示，左右方向键切页、F键全屏、打印为横向演示稿。
- 系统架构.png、历史延迟指标.png、固定样衣对照.jpg：已在论文中引用，历史数据与抽帧边界见正文。
- 验证报告.md、实验数据摘要.json、毕设材料包.zip：本轮检查、可追溯统计与材料归档。

## 运行

在virtual_tryon目录执行：

```powershell
npm ci
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-demo.ps1 -Demo
```

首页：http://127.0.0.1:8766/

免GPU演示：http://127.0.0.1:8766/studio?demo=1

真实AI工作台：http://127.0.0.1:8766/studio

无GPU模式仅包含交互、上传与本地相机，不产生真实换衣结果。资源恢复后确认原工作空间已运行，再执行scripts/start-demo.ps1 -Remote；脚本不自动启动工作空间。
